What is a UUID?

A Universally Unique Identifier (UUID) is a 128-bit value used to identify records, objects, events, and resources. UUIDs are commonly represented as 32 hexadecimal characters separated into five groups by hyphens. A GUID is Microsoft's term for a globally unique identifier and commonly uses the same textual format.

UUID versions at a glance

  • UUID v4: uses random or pseudo-random data, with version and variant bits reserved by the format.
  • UUID v5: creates a repeatable identifier from a namespace and name using SHA-1. The same namespace and name produce the same UUID.
  • UUID v7: includes a Unix-epoch millisecond timestamp and random data, making values generally time-sortable.

Choose a version based on your application requirements. UUID v5 is useful for deterministic IDs, while v4 is a common general-purpose choice and v7 can help with time-oriented database indexing. Always check the requirements of your database, framework, and application.

Frequently Asked Questions

Is DevIDTools.com free to use?

Yes. The tools provided on this page are available to use without creating an account.

What is the difference between UUID and GUID?

UUID and GUID generally refer to the same 128-bit identifier format. GUID is a term commonly used in Microsoft ecosystems.

Which UUID version should I choose?

UUID v4 is a common random option, v5 is deterministic for a namespace and name, and v7 is designed to be time-sortable.

Can I generate multiple UUIDs at once?

Yes. Choose a quantity from 1 to 100 in the UUID generator and generate a batch.

Does the UUID validator check whether a UUID is globally unique?

No. It checks formatting and reports the apparent version and variant. It cannot prove that no other system has generated the same value.

Is a UUID a secure password?

A UUID should not be treated as a password or as the only protection for a private resource. Use a dedicated authentication and secrets-management approach.

Why does UUID v5 need a namespace and name?

UUID v5 combines a namespace UUID and a name to generate a stable identifier. Reusing the same inputs returns the same identifier.

Does the JSON formatter send my data to a server?

The formatting operation is performed in your browser by this page's JavaScript. As with any website, review hosting and privacy details before entering sensitive data.
